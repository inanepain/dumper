= 1.17.0 @2025 Dec 08
:revnumber: 1.17.0
:revdate: 2025-12-08

* *update*: Console output divider line now stretches across the console width.
* *update*: `Dumper::dump` methods now accept `OptionsInterface` objects.
* *new*   : `Type::Todo` new type, when enabled adds todo entries to dump log.
* *new*   : `Dumper::todo` alias for `Dumper::dump` that is configured for `Type::Todo`.
* *new*   : `Dumper::isWindows` new method to check if running on Windows, need for column width.
* *new*   : `Dumper::columns` new method to get console width.
* *new*   : `Dumper::parseDepth` new instance property and `dump` `option` for custom parsing depth.
* *update*: Tweaked the UI for dumps a little.
* *update*: Cli colours: label = cyan.
* *global*: fix some minor grammar and spelling errors.
* *fix*   : fixed output when buffering disabled.
* *fix*   : fix output when `$bufferOutput = false` and `$enabled = false`.
* *update*: `dd/da` PHPDoc.
